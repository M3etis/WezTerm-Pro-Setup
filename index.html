Features

Всё, что делает терминал
повседневным инструментом

Не «ещё один dotfiles». Цельная система UI, клавиш и производительности.

Powerline tab bar

Скруглённые powerline-разделители, иконки процессов через Nerd Font, hover-состояния и мгновенная реакция на смену вкладки.

Rich status bar

Git-ветка и dirty-состояние, версии Python/Node/Rust/Go, Docker-контекст, kubectl, CPU/RAM с лейблами, батарея, hostname при SSH.

Tmux-style leader

Ctrl+A с таймаутом 1 сек. Vim-навигация по панелям, split’ы, zoom, workspaces — без переучивания мышечной памяти.

WebGPU · 120 fps

GPU-фронтенд с ограничением частоты кадров, разумный scrollback и platform-aware настройки для macOS, Linux и Windows.

Modular architecture

Конфиг разбит на config/, ui/, utils/. Каждый модуль экспортирует apply() — правьте точечно и перезагружайтесь.

Kitty graphics

Отображение изображений прямо в терминале по kitty graphics protocol — скриншоты, превью, tui-галереи.

Toast notifications

Кастомные уведомления при bell-событиях в неактивных панелях — фоновые задачи не теряются.

One-click installers

Windows .exe и macOS .dmg уже содержат WezTerm, Nerd Fonts и полный конфиг. Никаких предварительных зависимостей.

Architecture

Модульно из коробки

Не монолитный init.lua. Каждый слой отвечает за своё.

1

config/

Appearance, fonts, keys, mouse, domains, performance, workspace, behavior — восемь узких модулей.

2

ui/

Tab bar, status bar, notifications, components, palette, icons, powerline separators — event-driven UI.

3

utils/

Git (с кешем), battery, hostname, cwd, platform, process, path, formatting — переиспользуемые утилиты.

4

installer/

NSIS для Windows, pkgbuild + create-dmg для macOS. Бандл с шрифтами и полным конфигом.

Install

Два пути — оба рабочие

Рекомендуем инсталлятор. Скрипт — для Linux и тех, кто любит исходники.

macOS · Linux
# клонировать и запустить
git clone https://github.com/M3etis/WezTerm-Pro-Setup.git
cd WezTerm-Pro-Setup
chmod +x install.sh
./install.sh
Windows · PowerShell (Admin)
# клонировать и запустить
git clone https://github.com/M3etis/WezTerm-Pro-Setup.git
cd WezTerm-Pro-Setup
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1

WezTerm-Pro-Setup-2.0.0.dmg (~39 МБ) или .exe (~78 МБ) со страницы Releases.

Установите

Windows: двойной клик по .exe. macOS: откройте DMG и запустите .pkg. Шрифты и конфиг встанут сами.

✓

Увидите Catppuccin Mocha, powerline-табы сверху и status bar снизу. Если иконки «квадратами» — перезайдите в сессию.
